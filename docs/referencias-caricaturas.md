# POKÉPOL: referências para os caricaturistas

Levantamento feito em 16/10/2026. Nenhuma imagem foi baixada ou copiada. Caricaturas de outros artistas aparecem apenas como link e como lista de traços a exagerar.

## Como ler a tabela

- **Foto oficial**: registro conferido na API do Senado (`legis.senado.leg.br/dadosabertos`) ou da Câmara (`dadosabertos.camara.leg.br/api/v2/deputados`). Quando o político não tem mandato atual, a coluna indica o que foi possível encontrar, sem registro oficial confirmado.
- **Traços**: quando não há caricatura de referência, o texto indica "(art)" e vem do campo `art` de `web/js/data.js`, não de um cartunista.
- Licenças: nenhuma imagem de referência foi verificada como de uso livre.

## Resumo

- Com alguma referência de caricatura ou charge de cartunista: 8 (garotinho, boiadeiro, tarifardo, cunhamon, temerario, pedalita, golpenaro, carluxo, este último só autorrepresentação).
- Só com memes ou caricaturas feitas por IA, sem uso recomendado: 2 (abinzinho, renanzilla).
- Sem nenhuma referência encontrada: 24.

## Pendências

- A busca web trouxe sobretudo notícias. Para os 24 sem referência, vale procurar nos acervos de A Gazeta, Folha, O Globo e Estadão, e de cartunistas como Angeli, Laerte, Aroeira, Amorim e Latuff.
- A API do Wikimedia Commons deu erro 429 (limite de requisições). As categorias de Delcídio, Palocci e Machado existem, mas não foram verificadas as licenças das imagens.
- Os políticos sem mandato atual (ex-parlamentares e ex-executivos) não têm registro conferido nas APIs. Para eles, o caminho é o Commons ou os arquivos de agências oficiais.
