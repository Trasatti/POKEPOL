# Regra: delegar para modelos mais baratos

- Preferir agentes Sonnet/Haiku para tarefas delegáveis (pesquisa, mapeamentos, pixel art, sprites a partir de fotos). Haiku para pesquisa simples; Sonnet para arte e análise.
- O motor (game.js, integração) fica com o agente principal porque as peças precisam encaixar.
- Fotos de pessoa real: sempre verificar identidade pelo registro oficial (nome civil, partido, UF) antes de usar — rosto errado em personagem "corrupto" é risco de difamação.
