# Créditos — assets/landmarks

Todos os sprites desta pasta (cartões-postais das capitais e sedes de governo) são
**pixel art original**, criada para o projeto POKÉPOL por código (Python + Pillow,
scripts em `tools/landmarks/`). Nenhuma imagem externa foi copiada, traçada ou
reaproveitada; as referências foram apenas o conhecimento geral sobre a aparência
dos monumentos. A paleta e o estilo (contorno escuro, 3 tons de sombreamento, luz
no topo-esquerdo) seguem o tileset em `assets/tiles/` (ver `assets/CREDITOS.md`).

Para regenerar: `python tools/landmarks/build.py`.
