# Créditos e verificação das fotos-base dos sprites

Sprites são caricaturas geradas por `tools/make_caricatures.py` a partir de retratos. Registros vêm das APIs oficiais (Câmara/Senado): nome civil, partido e UF conferidos pelo id da API. Fotos Câmara/Senado: uso livre com crédito (Agência Câmara / Agência Senado). Fotos Wikimedia Commons: licença indicada; a identidade nesses casos se apoia no título do arquivo no Commons (pessoas sem registro no Congresso, ou foto mais recente).
